# 阶梯英语

面向中国大陆用户的原创英语学习网站原型。页面和交互依据对 ForumFlash 公开界面的功能观察设计，未复制其代码、品牌素材或课程正文。

## 运行

项目无需安装依赖。用本地 HTTP 服务打开项目目录，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。直接打开 `index.html` 也能使用，但本地服务器更适合开发与测试。

## 已实现

- 响应式首页、导航、三条课程路线和顺序解锁
- A1 语法课程理论、Easy/Medium/Hard 练习、单题计时、反馈、历史与星级进度
- 两类词汇路线、翻面词卡、记忆评价和收藏到复习
- 手动创建复习卡组、浏览器本地进度、个人资料与 JSON 导出
- 学习资料展示与筛选、写作练习输入和字数统计

## 当前边界

这是前端原型。数据保存在浏览器 `localStorage`，没有跨设备同步。练习题和课程说明是原创演示内容，不对应原站题库。Easy、Medium 的 80% 通过线与 XP 数值为可调整的暂定规则；Hard 使用 100% 规则。AI 写作评分、复习文件导入、真实账号和后端持久化尚未接入，界面不会假称已经完成评分。

观察依据见工作区中的 `ForumFlash_中文版功能复刻规格.md`；后续开发应以其中“已实测／待验证”标记更新规则。
