# 阶梯英语

面向中国大陆用户的原创英语学习网站原型。页面和交互依据对 ForumFlash 公开界面的功能观察设计，未复制其代码、品牌素材或课程正文。

## 运行

项目无需安装依赖。用本地 HTTP 服务打开项目目录，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。直接打开 `index.html` 也能使用，但本地服务器更适合开发与测试。

## 已实现

- 响应式首页、导航、三条课程路线和顺序解锁
- A1 语法 19 课各自独立的原创讲解、公式、示例、常见错误与对应题目；前 3 课各有 20 道不同题目
- Easy/Medium/Hard 练习、单题计时、反馈、历史与星级进度
- 25 个主题各 10 张首课词卡，以及 CEFR A1 的前 5 课词卡；支持翻面、记忆评价和收藏到复习
- 词汇课必修学卡与词义练习，达到 80% 才完成课程；选修听写与发音自测，不熟悉的词自动加入复习
- 手动创建复习卡组、浏览器本地进度、个人资料与 JSON 导出
- 6 篇可阅读的原创学习资料，涵盖 A1 阅读与词汇、A2 过去时、B1 段落写作；每篇有例句、自测与答案
- 写作练习输入和字数统计

## 当前边界

这是前端原型。数据保存在浏览器 `localStorage`，没有跨设备同步。练习题和课程说明是原创内容，不对应原站题库。除 A1 语法外的语法级别、主题词汇首课以后的课程，以及 CEFR A1 第 6 课以后仍缺原创正文；路线会标记“内容制作中”。A1 第 4—19 课当前每课只有 4 道独立题，页面会显示实际题量，不再重复题目凑数。Easy、Medium 的 80% 通过线与 XP 数值为可调整的暂定规则；Hard 使用 100% 规则。发音仅使用浏览器朗读与学习者自评，没有自动语音评分。AI 写作评分、复习文件导入、真实账号和后端持久化尚未接入，界面不会假称已经完成评分。

观察依据见工作区中的 `ForumFlash_中文版功能复刻规格.md`；后续开发应以其中“已实测／待验证”标记更新规则。
