# ForumFlash 最新源码本地运行（Windows）

旧目录 `已构建成品-dist/` 是静态快照，不含最新修改。本目录 `local-run/` 直接用 `client/`、`server/` 的最新源码构建并运行完整站点（含后端接口与数据库）。

## 一键运行

双击 `启动.bat`，然后访问 <http://127.0.0.1:60002/>。首次运行前，请先在本目录执行 `npm ci` 安装依赖。

## 手动运行

在 `local-run/` 目录的终端中依次执行：

```powershell
npm run build:client    # 用 Vite 构建最新前端
npm run build:backend   # 用 esbuild 打包 server/src/actions.ts
npm start               # 启动统一服务（静态页面 + /actions 接口）
```

默认端口为 60002。若端口被占用，可先设置 `$env:PORT=60003`，然后运行 `npm start`。

## 原理

原项目依赖 Muse Spaces 平台的 `@hatch/space-sdk`（含私有构建器与 RPC 层），本机无法安装。本方案做了最小等价替换，未改动任何原始源码：

- `shims/space-sdk-client.ts` — 替换客户端 SDK 的 `createActionClient`（改为 POST `/actions`）与 `spaceQueryClient`。
- `shims/space-sdk-server.ts` — 替换服务端 SDK 的 `defineAction` / `z` 类型层。
- `backend-entry.ts` — 把原始 `server/src/actions.ts` 与 `schema.ts` 原样打包，业务逻辑一行未改。
- `server.mjs` — 用 Node 22 内置 `node:sqlite` + Drizzle `sqlite-proxy` 驱动提供数据库，承载全部 19 个接口。
- `vite.config.mjs` — 让 Vite 从 `client/src` 编译最新前端，并解析依赖。

## 已知限制

- 数据库为本地 `app.db`（自动创建），学习数据仅存本机。
- `gradeWriting`（雅思写作批改）原本调用平台大模型，本地改为**启发式占位评分**（结构一致，分数非真实模型结果）；如需真实评分，可在 `server.mjs` 的 `ctx.inference.complete` 处接入模型 API。
- 首次安装依赖需联网（npm）。已安装则无需重复。
